Software improvements and new functionality added to MicrospectroscopyPlugin 1.0.0

New Features

	1. Interface to allow real-time display of '1D' binned spectrum in a dedicated display window
	2. X-axis scaled and abelled according to calibration
	3. Y-axis labelled with 'intensity'
	4. Y-axis displays scientific notation
	5. Cursor to step through spectrum profile
	6. Adjustable X and Y scales (range)
	7. Ability to zoom in and out of spectrum trace
	8. Ability to minimise and maximise display window
	9. X and Y co-ordinates of cursor displayed beneath spectrum display field in real-time
	10. Wavelength and current grating displayed below spectrum display field
	11. Normal and background spectrum displayed in different tabs that can be changed by one mouse click
	12. Save as ASCII available via File menu and as a shortcut on main window. Metadata appended to end of ASCII file
	13. Open ASCII files available via File menu and as a shortcut on main window
	14. ROI statistics available.
	15. Possible to control live and Multi-D acquisitions from plugin Window.
	16. Review of Multi-D acquisitions.
