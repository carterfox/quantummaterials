Agilent ENA Series Instrument Driver Readme

To rate this instrument driver, go to the driver download page on the Instrument Driver Network.

1. Overview

Instrument Driver Technology: LabVIEW Plug and Play (project-style)
Manufacturer: Agilent
Supported Language(s): LabVIEW
Supported Model(s): E5061A, E5062A, E5063A, E5061B, E5070B, E5071B, E5071C, E5072A, E5080A, E5080B
Model(s) Tested: E5071B, E5071C, E5061B, E5072A, E5080A (tested by KT)
Interface(s): GPIB, Ethernet, USB
Firmware Revision(s) Tested: A.08.00/A.01.10/A.01.03/Z.14.12.85

Certified: Yes
NI Supported: Yes
Source Code Available: Yes

Driver Revision: 2.4
Original Release Date: 3/2005
Current Revision Date: 07/19/2021

2. Required Software

Some software components need to be installed before using this instrument driver. The minimum versions of these components are listed below, and can be downloaded from the Download Site.

VISA 5.0 or later

Refer to the LabVIEW Help for more information about software requirements. You access the LabVIEW Help by selecting Help»Search the LabVIEW Help.

3. Known Issues


To report issues or provide feedback about this instrument driver, please contact technical support.

Many VIs do not contain a "%".; (period decimal selector) token to format the string containing a fractional number output.
File Manager.vi - If we try to delete directory in instrument its not possible.
Store.vi - Saving of entire instrument state isn't possible too. We think this problems are firmware bugs.
Application Example.vi - May not work when previously performed calibrations did not finish successfully. Same task performed using agena Interactive Application Example.vi should work.
Agilent ENA Series Configure Calibration.vi- Error occurred for some user in countries that do not use decimal point separator. To solve this problem, change the configuration(tools -> options..-> front panel -> de-select "use localized decimal point".)

REV 2.3 the models E5063A and E5080A were not tested by National Instruments; the driver might lacks ranges for them. However, Keysight did the testing for these models.
The E5080A is supported through the E5071C code emulation mode. You must enable the E5071C code emulator from the instrument front panel by pressing System -> System Setting -> Code Emulation -> 5071.
