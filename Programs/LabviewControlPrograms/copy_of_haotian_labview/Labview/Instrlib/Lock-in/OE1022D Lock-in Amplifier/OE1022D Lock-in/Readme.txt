1. OE1022D disk's content
The CD-ROM is a complete set of OE1022D Lock-in amplifier, which contains Suite LabVIEW software, drivers and user manual of 0E1022D. Refer to the following info:

(1)OE1022D Software Driver: This folder contains the foundation drivers of OE1022D_Console_EN.exe software. If the computer is not installed on LabVIEW 2011 or later version of LabVIEW software, please install this drivers before using the OE1022D_Console_EN.exe.

(2)OE1022D_Console_USB: This folder contains PC EXE of the OE1022D Lock-in Amplifier which based on LabVIEW.

(3)USB Driver: This folder contains a USB driver. Please install the driver before using the USB port.

(4)OE1022D_introduction: This file introduces the performance characteristics of the OE1022D Lock-in Amplifier.

(5)OE1022D_User_Manual: This file is a manual for user. Please read carefully before using the OE1022D Lock-in Amplifier.


2. System Requirements

RAM: Recommend 1 GB or greater, Min: 512 MB
Disk Space: Recommend 1.5 GB or more, Min: 1 GB
Display: 1280x768 resolutions (min), Medium (16-bit) colors

3. Caution
Please read the user manual carefully before using the OE1022D Lock-in Amplifier.
